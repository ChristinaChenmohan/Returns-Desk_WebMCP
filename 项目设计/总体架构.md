总体架构

Agent-Ready Returns Desk：给小型电商/独立卖家用的“退换货处理台”。用户把订单、商品、退货政策放进去；买家或客服 agent 可以查询资格、生成退换货方案、创建 RMA、生成邮件、待人工批准。
主要支持三个解决方案：
换货：资格检查时展示目标 SKU 库存；人工批准时原子扣减库存并记录 `committed` 预留凭证。
原路退款：批准后生成模拟退款记录。
商店余额：立即可用但需要客户同意。

核心用户：
- 小型商家/客服：每天处理几十个售后请求，没有专门的客服系统。

WebMCP 工具只做参数接收、调用领域服务和压缩返回结果。
UI 按钮调用相同的领域服务接口。
浏览器端不直接读取或修改 D1。
ShopifyAdapter 接口隔离 mock 数据源，MVP 使用 DemoCommerceAdapter。
每位访客通过匿名 Demo Session 获得隔离数据空间。
“Reset Demo”只重建当前 Session 的 seed 数据。
所有影响状态的动作都写入 audit_events。
不需要在应用内部调用 LLM；Agent 由 ChatGPT/浏览器提供，政策判断与方案成本由确定性代码完成。
